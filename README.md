## 🚀 Getting Started

### Prerequisites
- Node.js >= 18.17.0
- npm >= 9.0.0

### Installation
```bash
npm install
```

### Local Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build
```bash
npm run build
npm run start
```
